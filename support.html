I deleted something by accident

Look for a tab named “(backup …)” at the bottom of your spreadsheet. SheetTidy copies the tab before any destructive action, so unless you switched that option off, your data is still there with a timestamp in its name.

If there's no backup tab, try File → Version history → See version history in Google Sheets™ and restore the version from just before you ran the tool.

Note that Ctrl+Z will not undo changes made by any Google Sheets™ add-on, including this one. That's a limitation of Google Sheets™, not something we can fix — which is exactly why the backup option exists and why it's on by default.

Installing and opening

Where is it after I install it?

Open any spreadsheet, then Extensions → SheetTidy → Open SheetTidy. The panel opens on the right. If you don't see it in the Extensions menu, reload the spreadsheet page.

My workplace won't let me install it

Some organisations only allow administrators to install Marketplace apps. Ask your Google Workspace administrator to approve SheetTidy for your account or your team.

Licence keys

Where do I find my key?

It's in the receipt email from Lemon Squeezy sent when you purchased. Search your inbox for “SheetTidy” or “Lemon Squeezy”, and check your spam folder.

Where do I enter it?

Open the SheetTidy panel, scroll to the bottom, paste the key into the box and click Activate. It's stored in your Google account, so you only do this once.

My key won't activate

  • Check for a stray space at the start or end when you pasted it.
  • Make sure the whole key was copied, not part of it.
  • If you see “could not reach the licence server”, that's a connection problem rather than a bad key. Try again shortly.
  • Still stuck? Email us the key and we'll look it up.

Do I need a key on every computer?

No. A licence is attached to your Google account, so it follows you to any computer where you sign in to that account, in every spreadsheet you open.

Using the tools

It says my sheet is too big

The free version works on spreadsheets up to 250 rows. Above that you'll need a licence — every tool is otherwise identical.

Duplicates aren't being found

By default SheetTidy matches on every column, so two rows are only duplicates if every cell matches. If you want rows matched on an identifier like SKU or email, select that column in the duplicates list first.

Also check First row is headers is ticked if your sheet has a header row, so it isn't treated as data.

Rows that look identical aren't matching

Usually invisible whitespace. Run Trim spaces first, then look for duplicates again. Note that SheetTidy compares the displayed value, so a number formatted as text won't match the same number stored as a number.

Capitalisation changed cells I didn't want changed

If you select a range before clicking Apply, only that range is affected. With nothing selected it applies to the whole sheet. Restore from the backup tab and try again with a selection.

Privacy and permissions

Why does it need permission at all?

To read and change the cells in the spreadsheet you have open. SheetTidy uses the narrowest permission Google offers for this — access to the current spreadsheet only. It cannot see any other file in your Drive.

Does my data leave Google?

No. The only outbound connection SheetTidy ever makes is sending your licence key to our payment provider to check it's valid. Full detail is in the privacy policy.
